Tentang Saya

Saya adalah Fresh Graduate S1 Teknik Informatika lulusan tahun 2026 dari Universitas Langlangbuana dengan latar belakang Teknik Komputer dan Jaringan (TKJ). Memiliki minat mendalam dalam pengembangan perangkat lunak, web development, machine learning dan pengelolaan data. Saya terbiasa bekerja secara teliti, terstruktur, dan berorientasi pada penyelesaian masalah.

Selama kuliah, saya aktif mengembangkan kemampuan pemrograman dan mengintegrasikan logika backend (seperti Laravel, CodeIgniter, dan PHP) dengan antarmuka web modern menggunakan Tailwind CSS dan JavaScript. Saya juga memiliki sertifikasi kompetensi dari Dicoding dan merupakan alumni Bangkit Academy 2024.
